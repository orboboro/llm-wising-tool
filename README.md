# llm-wising-tool
A simple RAG system aimed to wise up LLMs on the choosen documentation. 
One needs first to upload in the working directory the txt document he wants his LLM to be wised up on. Then, one needs to open execution.py, choose an llm between the ones available on the Hugging Face platform and set its name in the model parameter of the huggingface_API_calling function. Eventually one needs to set a query and execute the file.
